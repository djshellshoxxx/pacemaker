# Trademark search worksheet: "Pacemaker" (RS-06 section 5)

Status: **NOT DONE.** This is a worksheet only. No search has been run for this document and nothing here is legal
advice. Run the searches, record the results below, and get a trademark attorney's opinion before spending money on
the website domain, artwork or a paid launch.

## Known prior use (from RS-06 and RS-01)

- 2008 "Pacemaker" DJ device by Tonium: prior use in class 9 (to be confirmed by registry search).
- The word also names medical devices (class 10), many software products and services (classes 9, 42), and is a common
  word; expect crowded results and descriptive-word arguments in both directions.

## What to search

Goods/services: Nice class 9 (recorded and downloadable software, audio plugins, audio software, audio hardware), also
class 41 (music production services), class 42 (SaaS), class 10 (medical, for conflict context), class 15 (musical
instruments/accessories) for hardware like the Pi Box.

Marks: PACEMAKER (exact), PACE MAKER, PACEMAKR, PACEMAKERS, plus phonetic and translation variants, and logo marks.

## Evaluation questions

1. Any live registration or pending application for PACEMAKER (or confusingly similar) covering audio software,
   plugins, music hardware or related services in class 9, 41, 42 or 15? Owner, filing date, status, use evidence.
2. Does the Tonium Pacemaker device still have an active owner, or is the mark abandoned/expired?
3. Are there unregistered (common law) users in audio, DJ or music tech, including Pacemaker-named plugins or apps?
4. Is a coexistence argument available (different goods, e.g. beat-sync software vs. DJ hardware)? That is for counsel.
5. Is the name available as a domain, store listing and handle at acceptable cost?

Rules for picking a fallback: avoid other companies' marks (Ableton, Link, Live, Logic...), avoid purely descriptive
terms where possible (weak protection), keep the tagline compatible ("The band sets the tempo. The machine keeps up."),
and check domains early.
