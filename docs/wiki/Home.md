# PACEMAKER Wiki

PACEMAKER listens to a live drummer and predicts the band's tempo, beat phase and bar position. It publishes that clock as
Ableton Link, MIDI clock, OSC and an audio sync pulse. Planned: VST3, CLAP, AU and LV2 plugins, a standalone app and a headless
Raspberry Pi appliance. Not shipped yet. The current code is the C++17 tracking engine with an offline evaluation CLI and tests.
